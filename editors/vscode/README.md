# Chkoupi-lang VS Code Extension

Syntax highlighting and language configuration support for **Chkoupi-lang** (`.dz` files).

## Installation

### Manual Installation
Copy the `vscode` folder to your VS Code extensions directory:
- **Windows**: Copy to `%USERPROFILE%\.vscode\extensions\dzxpert.chkoupi-lang-1.0.0`
- **macOS/Linux**: Copy to `~/.vscode/extensions/dzxpert.chkoupi-lang-1.0.0`

Alternatively, you can symlink it:
```bash
ln -s "$(pwd)" ~/.vscode/extensions/dzxpert.chkoupi-lang-1.0.0
```

Restart VS Code, and any file ending with `.dz` will have syntax highlighting enabled!
